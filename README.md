## Что умеет

| Возможность | Описание |
|-------------|----------|
| 🗂️ **Создание файлов** | Агент пишет код и сохраняет файлы в проекте |
| ✏️ **Редактирование** | Точечно правит существующие файлы |
| 🖥️ **Выполнение команд** | Запускает `python`, `git`, `pip`, `npm` и др. |
| 🔁 **Агентный цикл** | До 15 итераций — сам проверяет результат и исправляет |
| 🔒 **Безопасность** | Whitelist команд, защита от выхода за пределы проекта |
| 📝 **Логирование** | Все действия пишутся в `logs/agent.log` |
| 🎨 **Красивый UI** | Стриминг ответов, спиннер, цветные статусы |

## Быстрая установка (Windows)

### Шаг 1 — Скачай или клонируй проект
```bash
git clone <repo-url> D:\copilot\my-ai-copilot
cd D:\copilot\my-ai-copilot
```

### Шаг 2 — Запусти скрипт установки
Дважды кликни по файлу **`setup.bat`** или выполни в терминале:
```powershell
.\setup.bat
```

Скрипт автоматически:
1. ✅ Проверит версию Python
2. ✅ Установит все зависимости (`pip install -r requirements.txt`)
3. ✅ Попросит ввести NVIDIA API Key и создаст `.env`
4. ✅ Создаст рабочую папку `logs/`

## Ручная установка

### 1. Зависимости
```powershell
pip install -r requirements.txt
```

### 2. API-ключ
Создай файл `.env` в корне проекта:
```env
NVIDIA_API_KEY=nvapi-xxxxxxxxxxxxxxxxxxxxxxxx
NVIDIA_MODEL=meta/llama-3.1-8b-instruct
```

> 🔑 Ключ бесплатно получаешь на [build.nvidia.com](https://build.nvidia.com) → Sign In → Get API Key

## Запуск

### 🤖 Агентный режим (рекомендуется)
Модель сама создаёт файлы, запускает команды, анализирует ошибки и итерирует:
```powershell
python main.py --project D:\мой-проект --agent
```

### 💬 Чат-режим
Обычный диалог с поддержкой файловых операций:
```powershell
python main.py --project D:\мой-проект
```

### 📌 Параметры командной строки
| Флаг | Описание | По умолчанию |
|------|----------|--------------|
| `--project` / `-p` | Папка проекта | Текущая директория |
| `--agent` | Включить агентный режим | Выключен |

## Как работает агент

```
Пользователь → [Запрос]
                    ↓
              NVIDIA API (LLM)
                    ↓
           tool_call: create_file
                    ↓
        ⏳ Выполняю: create_file для src/app.py
                    ↓
           [Результат → модели]
                    ↓
           tool_call: execute_cmd
                    ↓
        ⏳ Выполняю: execute_cmd для python app.py
                    ↓
           [Анализ вывода]
                    ↓
        ✅ Агент завершил задачу.
```

## Доступные инструменты агента

| Инструмент | Описание |
|-----------|----------|
| `create_file` | Создать / перезаписать файл |
| `edit_file` | Отредактировать строки в файле |
| `delete_file` | Удалить файл |
| `make_directory` | Создать директорию |
| `read_file` | Прочитать содержимое файла |
| `list_directory` | Список файлов в папке |
| `execute_cmd` | Выполнить команду в терминале |

## Структура проекта

```
my-ai-copilot/
├── main.py                  # Точка входа, CLI, агентный цикл
├── setup.bat                # ⚡ Скрипт быстрой установки
├── requirements.txt         # Зависимости
├── .env                     # API-ключ (не коммитить!)
│
├── core/
│   ├── llm_client.py        # NVIDIA API клиент, стриминг, tool-calls
│   ├── agent_executor.py    # Выполнение инструментов агента
│   ├── functions.py         # Схемы инструментов (OpenAI tools format)
│   ├── security.py          # Whitelist команд, защита путей
│   ├── file_ops.py          # Парсинг и выполнение файловых операций
│   └── context_manager.py   # Чтение структуры проекта для контекста
│
├── ui/
│   └── screen.py            # Отрисовка UI, спиннер, стриминг
│
├── tests/
│   ├── test_security.py     # Тесты безопасности (20 штук)
│   └── test_agent_executor.py  # Тесты инструментов (15 штук)
│
└── logs/
    └── agent.log            # Лог всех действий агента
```
